# MyBooks on the Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A desk website, at `marioruidacosta.github.io/MyBooksNewGeneration/`, for managing the same cloud library as the phones.

**Architecture:**
- **Front end:** a static Vite, React and TypeScript app in `web/`, acting as one more synced device.
  - It loads the whole cloud library with `sync_pull`, keeps it in memory and IndexedDB, writes through `sync_push` with per-field times, and listens on `library:<owner>`.
- **Server pieces:**
  - An Edge Function `lookup` handles BNP and Google Books.
  - A read-only RPC `my_shared_book_ids()` lets the site publish to the community only for books the phones share.

**Tech Stack:** Vite 5, React 18, TypeScript 5, `@supabase/supabase-js` 2, TanStack Table 8, TanStack Router 1, `idb` 8, `fflate` (backup ZIP), Vitest 2 with React Testing Library and `fake-indexeddb`, Deno for the Edge Function, GitHub Actions and Pages.

**Spec:** `docs/superpowers/specs/2026-11-16-web-app-design.md`

## Global Constraints
- **Node:** use the portable Node in `C:\Users\mcosta\devtools\node-v18.20.8-win-x64`, so every package must support Node 18.
  - Set `NODE_USE_SYSTEM_CA=1` for npm behind the TLS-inspecting proxy. Never disable TLS checks.
  - Run commands with `timeout`.
- **Supabase:**
  - The URL and anon key come from build-time env `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`. Locally they live in `web/.env.local`, which is git-ignored and filled from `../local.properties` without echoing. In CI they are repository variables.
  - Never use the service-role key.
- **Copy is English** and matches the app's words: "To read", "Reading", "Read", "To buy", and so on.
- **Sync rules (the app is the reference, `shared/src/commonMain/.../sync`):**
  - **Field names** follow `SyncCodec.kt`: `isbn`, `title`, `authors`, `publisher`, `published_year`, `page_count`, `cover_url`, `description`, `status`, `rating`, `notes`, `date_added`, `date_read`, `date_started`, `current_page`, `progress_percent`, `review`, `tags`, `series`, `series_number`, `lent_to`, `lent_on` and `deleted`. Quotes use `book_id`, `text`, `page`, `date_added`, `position` and `deleted`. Challenges use `goal` and `deleted`, with the year as the id.
  - **Tags** are one text joined with `"\n"`.
  - **Status values** are the enum names `READING`, `TO_READ`, `READ` and `WISHLIST`. Label "To buy" = `WISHLIST`.
  - **Merge (`mergeFields`):** per field, the remote value wins only when its time is greater than the local time (missing counts as −1). `deleted` is a field like any other.
  - **Push:** batches of at most 100 changes. Each change is `{table, id, fields, times, deleted?}`.
  - **Covers:** the `cover_url` value `"photo"` means the photo is at `covers/<owner>/<id>.jpg`. It must be a JPEG of 2 MB or less, at most 1000 px on its long side. The `cover_url` time is re-stamped on every upload.
- **Duplicate rule (`CatalogBooks.findInLibrary`):** the same ISBN, otherwise the same `catalogTitleKey(title)` and the same `authorKey(first author)`. Port `searchKey`, `catalogTitleKey` and `authorKey` exactly.
- **Gates:**
  - Web: `cd web && npm run lint && npm test -- --run && npm run build`.
  - Function: `deno test supabase/functions/lookup`. CI only, since there is no local Deno.
  - Database: the pgTAP CI job, `supabase.yml`.
- **Production writes (stop and ask the person first):**
  - deploying the Edge Function;
  - setting the Supabase secret `GOOGLE_BOOKS_API_KEY`;
  - applying the migration;
  - enabling GitHub Pages;
  - adding the repository variables.

## Review Focus
1. **A phone and the site edit the same book at the same time.** Each field ends with the newest edit on both, with no lost field and no ping-pong. Pinned by Task 3 `concurrentEditsKeepTheNewestField`.
2. **The site is closed with changes still waiting** (offline, or the tab closed mid-save). They are sent at the next visit. Pinned by Task 3 `queuedChangesSurviveAReload`.
3. **Adding a book that's already in the library** (same ISBN, or same title and author with another ISBN or none). The existing book opens instead of a duplicate being added. Pinned by Task 7 `addingAnExistingBookOpensIt`.
4. **A Goodreads import containing books the library has.** They are merged, not duplicated, and the preview counts are right. Pinned by Task 8 `importMergesExistingBooks`.
5. **A change to a book that a phone excluded from sharing.** Nothing is published. Pinned by Task 10 `anUnsharedBookIsNeverPublished`.

**Produces:**
- `interface SyncApi { pull(after: number, max: number): Promise<{rows: SyncRow[], last: number}>, push(changes: Change[]): Promise<{applied: string[], rejected: {id: string, reason: string}[]}>, onPing(owner: string, cb: () => void): () => void }`.   - `subscribe(cb)`.
  - `status: 'saved' | 'saving' | {offline: number} | {rejected: string}`
